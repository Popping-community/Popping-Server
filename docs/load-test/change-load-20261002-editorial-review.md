8개 값을 산술평균했다. 아래 값은 각 회차의 평균이며 단위는 코어다.

| A 회차 | 평균 | B 회차 | 평균 |

중앙값 차이는 약 0.000321코어다. 범위도 겹쳐 MySQL CPU에서 뚜렷한 차이는
확인하지 못했다. 다만 이는 MySQL 전체 CPU의 이동창 지표이지 추가 SELECT만의
한계 비용 또는 정확한 120초 CPU 사용량 적분은 아니다. 1코어 중 약 75% 사용을
처리량 여유 25%로 환산하지 않는다. 앱 CPU 포화와 DB CPU 사용량을 구분하고,
순차 요청 실험에서 확인한 요청당 SELECT 증가는 계속 명시한다.
